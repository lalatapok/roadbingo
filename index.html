ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ мобильного приложения «Дорожное Бинго» (Road Bingo) Дата последнего обновления: 16 августа 2026 года 1. ОБЩИЕ ПОЛОЖЕНИЯ 1.1. Настоящая Политика конфиденциальности описывает порядок обработки информации при использовании мобильного приложения «Дорожное Бинго» (Road Bingo) (далее — «Приложение»). 1.2. Приложение представляет собой игровое приложение для совместного времяпрепровождения детей и родителей во время поездок. 1.3. Приложение распространяется бесплатно. 1.4. Для использования основных функций Приложения регистрация, создание учётной записи или предоставление персональных данных не требуются. 1.5. Настоящая Политика применяется к информации, обрабатываемой Приложением в рамках его текущей версии. 2. КАКИЕ ДАННЫЕ ОБРАБАТЫВАЕТ ПРИЛОЖЕНИЕ 2.1. Приложение не осуществляет сбор персональных данных пользователей и не передаёт их разработчику или иным третьим лицам. 2.2. Приложение не запрашивает у пользователя: * имя и фамилию; * номер телефона; * адрес электронной почты; * адрес проживания; * данные учётных записей; * сведения о местоположении; * фотографии, видео или аудиозаписи; * иные персональные данные для регистрации или идентификации пользователя. 2.3. Приложение не требует создания аккаунта и не осуществляет авторизацию пользователей. 2.4. В текущей версии Приложение не содержит рекламных систем, сторонних рекламных SDK и систем аналитики. 2.5. В текущей версии Приложение не использует сетевое соединение для передачи пользовательских данных на серверы. 3. ДАННЫЕ, СОЗДАВАЕМЫЕ И ХРАНЯЩИЕСЯ НА УСТРОЙСТВЕ 3.1. В процессе использования Приложения пользователь может создавать игровые данные, которые сохраняются локально на его устройстве. К таким данным относятся: * названия сохранённых поездок; * отметки найденных игровых объектов; * количество отметок игровых объектов; * настройки Приложения, в том числе состояние звука. 3.2. Пользователь самостоятельно определяет содержание названий сохранённых поездок. В связи с этим рекомендуется не указывать в названиях поездок сведения, которые пользователь не хочет хранить на устройстве. 3.3. Указанные игровые данные используются исключительно для работы соответствующих функций Приложения. 3.4. Данные сохраняются локально на устройстве и в текущей версии Приложения не передаются разработчику или на удалённые серверы. 3.5. Удаление Приложения с устройства, как правило, приводит к удалению локально сохранённых данных Приложения. Возможность сохранения данных средствами операционной системы или резервного копирования устройства зависит от настроек самого устройства и операционной системы и не контролируется разработчиком. 4. РАЗРЕШЕНИЯ ПРИЛОЖЕНИЯ 4.1. В текущей версии Приложение использует разрешение VIBRATE. 4.2. Данное разрешение используется для обеспечения тактильной реакции при взаимодействии пользователя с игровыми карточками. 4.3. Разрешение VIBRATE не предоставляет Приложению доступа к контактам, сообщениям, фотографиям, местоположению или иным персональным данным пользователя. 5. ПЕРЕДАЧА ДАННЫХ ТРЕТЬИМ ЛИЦАМ 5.1. В текущей версии Приложение не передаёт пользовательские данные третьим лицам. 5.2. Приложение не продаёт и не предоставляет пользовательские данные третьим лицам для их использования в рекламных или иных целях. 5.3. В текущей версии Приложение не использует сторонние сервисы аналитики, рекламные SDK или иные сетевые сервисы, предназначенные для сбора информации о пользователях. 6. ЗАЩИТА ДЕТЕЙ 6.1. Приложение предназначено для семейного использования, в том числе совместного использования детьми и родителями во время поездок. 6.2. Приложение не требует от ребёнка или родителя предоставления персональных данных для использования основных игровых функций. 6.3.
